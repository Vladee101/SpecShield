# SpecShield

**Шлюз идентичности для безопасной разработки с ИИ-агентами.**

Локальное настольное приложение и CLI, позволяющие применять коммерческие
языковые модели — ChatGPT, Codex, Claude Code, Gemini — к проприетарному коду и
документам. SpecShield заменяет **деловую идентичность** устойчивыми
псевдонимами, оставляет **архитектуру** читаемой и переписывает ответ модели
обратно в ваши настоящие имена.

```text
Acme Bank offers Gold Business Subscription.        ORG_001 offers PRODUCT_001.

BillingService stores the subscription in     ──▶   BillingService stores the subscription in
customer_subscription and charges Stripe.           customer_subscription and charges PAYMENT_PROVIDER_001.
```

Обратите внимание, что́ **не** изменилось. `BillingService` и
`customer_subscription` уезжают дословно, и это не упущение, а смысл продукта:
агент, который не может прочитать вашу архитектуру, не может помочь её
развивать. Двойник, где `CustomerSubscription` превращён в `DTO_004`, не даёт
модели ничего, на чём можно строить.

> **Он убирает имена, а не смысл.** Двойник по-прежнему говорит, что делает ваш
> код. Если ваш секрет — сама *логика* или *архитектура*, не отправляйте их в
> коммерческую LLM ни с этим инструментом, ни без него. Подробно:
> [«Остаточный риск»](docs/Остаточный%20риск.md).

## Что скрывается и что сохраняется

| | Примеры | В двойнике |
|---|---|---|
| **Идентичность** — кто вы, с кем работаете, где работаете | `Vantor`, `Gold Business Subscription`, `Stripe`, `Jane Okafor`, `api.vantor-freight.com` | **Заменено** |
| **Структура** — что вы построили | `BillingService`, `CustomerSubscription`, `customer_subscription`, `POST /subscriptions` | **Сохранено** |
| **Секреты** — ключи, токены, строки подключения | `AKIA…`, `ghp_…`, `postgres://u:p@…` | **Затёрто односторонне**, не восстанавливается |

Девять категорий идентичности: организация, продукт, бренд, партнёр, платёжный
провайдер, персона, тенант, среда, домен. Любое структурное имя можно поимённо
повысить до идентичности — `specshield term settlement_ledger --entity-type
table`; по умолчанию не повышено ни одно.

Часть идентичности находится без подсказок: встроенная таблица примерно из
пятидесяти коммерческих сервисов (`Stripe`, `Twilio`, `Auth0`), правило формы
имени хоста и маркеры персон (`@author`, `Contact:`, `Reviewed-by:`). Остальное —
ваша компания, ваши продукты, ваши клиенты — угадать невозможно, и вы называете
это один раз.

## Быстрый старт

```bash
cargo build --release                      # бинарник в target/release/specshield
cd /path/to/your/project
export SPECSHIELD_PASSPHRASE='длинная фраза, которую вы не потеряете'

specshield init .
specshield term "Acme Bank" --entity-type organization

specshield scan docs/prd.md                # что нашлось, ничего не меняя
specshield sanitize docs/prd.md --envelope # двойник + преамбула для модели
# …отправить модели, забрать ответ…
specshield restore reply.md > restored.md
```

Для репозитория целиком:

```bash
specshield index
specshield export ../project-twin          # обезличенное дерево, импорты разрешаются
# …агент работает над ../project-twin…
specshield restore ../project-twin --out ../restored
specshield apply src/billing.ts --ai ../restored/src/billing.ts --branch feature/ai
```

Настольное приложение делает то же самое в окне:

```bash
cd app && npm install && npm run tauri dev
```

**Добавьте `.specshield/` в `.gitignore`.** Там лежит соответствие каждого
псевдонима настоящему имени, и это самый чувствительный артефакт, который
производит инструмент.

## Что гарантируется, а что нет

Три свойства проверяются тестами, а не заявляются:

- **`restore(sanitize(x)) == x` побайтно.** Свойство проверяется на всём
  эталонном корпусе.
- **Двойник разбирается, и его структура совпадает с оригиналом.** Если правка
  сломала бы файл, замена отменяется и файл проходит необезличенным — и об этом
  сообщается, а не выпускается сломанный результат.
- **Ничего не уходит в сеть.** У приложения нет ни HTTP-клиента, ни сетевых
  разрешений; весь список разрешений Tauri — три записи, и тест фиксирует, что
  их ровно три. CI гоняет весь набор тестов в сетевом пространстве имён без
  маршрута наружу.

Что **не** гарантируется, прямым текстом: бизнес-логика, алгоритмы и форма
архитектуры доходят до модели полностью; характерная предметная модель позволяет
переопознать организацию при всех заменённых именах; имя, которое вы никогда не
внесли в словарь, не защищено ничем.

### Метрики

Измеряются в CI на закоммиченном, размеченном вручную корпусе из семи
синтетических проектов, на каждом коммите.

| | Значение | Порог |
|---|---|---|
| Полнота, только правила | **49,0%** | — |
| Полнота, со словарём | **100%** | ≥ 95% |
| Точность | **98,0%** | ≥ 90% |
| Обнаружение секретов | **6 / 6** | 100% |
| Тесты | **439** | — |

Смотрите на левую строку. «Только правила» — это то, что детектор находит против
пустого хранилища, то есть всё, что есть у пользователя до того, как он
что-нибудь наберёт. Колонка «со словарём» в основном измеряет, что заполнение
словаря работает.

## Состояние

Движок работает и проверен через CLI. Что не готово:

- **Установщики не подписаны** — SmartScreen и Gatekeeper будут предупреждать.
- **Настольный интерфейс не проходили целиком** через запущенное окно Tauri; вся
  сквозная проверка сделана через CLI.
- **Хранилища учётных данных ОС нет** — парольная фраза является единственным
  путём к ключу.
- **Устойчивость псевдонимов через настоящий API модели не измерена.**

Полный список — [«Остаточный риск» §3](docs/Остаточный%20риск.md) и
[`TODO.md`](TODO.md).

## Устройство

Движок headless; приложение и CLI — драйверы к нему. Всё, что может приложение,
CLI может без графики.

```
crates/core/      модель, псевдонимы, правки, обнаружение, секреты,
                  обезличивание, восстановление, шлюз, сравнение
crates/parsers/   по одному парсеру на формат: markdown, sql, openapi,
                  yaml, json, typescript, plantuml, text
crates/vault/     SQLite + поэлементный AES-256-GCM, Argon2id, слепой индекс
crates/index/     обход дерева, BLAKE3, правила исключения
crates/project/   общий конвейер: индексация, экспорт, восстановление, шлюз
crates/git/       генерация и применение патчей
crates/cli/       бинарник specshield
app/              настольное приложение на Tauri v2 + React
corpus/           эталонный корпус: семь размеченных синтетических проектов
```

Rust 1.90+, edition 2024, `unsafe_code = "forbid"` во всём рабочем пространстве.

### Сборка и проверка

```bash
cargo build --release
cargo test --workspace                          # 439 тестов
cargo clippy --workspace --all-targets
cargo run -p specshield-cli -- report corpus --strict
```

CI выполняет восемь задач: `fmt`, `clippy`, `test`, `docs`, `corpus`, `deny`,
`perf` и `offline` — последняя гоняет весь набор в сетевом пространстве имён без
маршрута наружу, предварительно убедившись, что DNS там действительно нет:
тест, который прошёл бы и при доступной сети, не доказывает ничего.

## Безопасность

Хранилище — `.specshield/vault.bin`: SQLite, где каждое чувствительное значение
зашифровано по отдельности через AES-256-GCM под случайным ключом данных,
который сам обёрнут ключом от Argon2id из вашей парольной фразы. Каждый
шифротекст привязан к своей таблице, колонке и строке. Поиск даёт слепой индекс
(HMAC), а не расшифровка. Псевдонимы лежат открытым текстом намеренно — это
именно то, что отправляется модели.

**Парольная фраза не восстанавливается.** О ней нигде ничего не сохраняется.
Сделайте резервную копию и депонирование ключа в первый же день:

```bash
specshield backup ~/secure/project.vault.backup
specshield escrow ~/secure/project.escrow --escrow-passphrase '<вторая фраза>'
```

Если нашли проблему в безопасности — начните с
[«Модели угроз»](docs/Модель%20угроз.md): там перечислено, что заявлено, где
реализовано и чем проверяется. Заявление, которого там нет, заявлением и не
является.

## Лицензия

`UNLICENSED`, файла лицензии нет — по умолчанию это означает «все права
защищены». Прежде чем делать репозиторий публичным, решите этот вопрос: без
лицензии никто не вправе использовать код, даже если он виден.
